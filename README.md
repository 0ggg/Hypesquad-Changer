## Arabic Guide / الدليل العربي

- Python 3.8+
- تثبيت الحزم المطلوبة:
`
pip install -r requirements.txt
`

1. تثبيت الحزم المطلوبة:
   `
   pip install -r requirements.txt
   `
2. تشغيل الأداة:
   `
   python main.py
